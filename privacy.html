Privacy Policy

Last updated: 18 November 2026

Channel Uploader is a private tool used only by the owner of the Digital Shadows and HisStick YouTube channels.

What it accesses

With the channel owner's permission, the app uses Google OAuth to upload videos, set thumbnails and schedule publishing on the owner's own YouTube channels, and to read basic information about those channels.

How data is stored

The sign-in token is stored only on the owner's own computers. No data is sold, shared with third parties, or used for advertising. Google user data is used only to upload and manage the owner's own videos.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions.

Google API Services

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
